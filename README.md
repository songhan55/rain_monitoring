# 🌧️ Rain Monitoring: 스마트 도로 위험 감지 및 내비게이션 알림 시스템

실시간 기상 관측 데이터(강수량)와 도로 CCTV 실시간 영상 스트림을 연계하여 도로 침수, 싱크홀, 대형 도로 파손을 조기에 감지하고 운전자에게 능동적으로 알리는 안전 시스템 프로젝트입니다.

## 🏗️ 핵심 파이프라인 구조

1. **[기상청 API]** 초단기실황 강수량 모니터링 $\rightarrow$ 호우/위험 권역 도출 (트리거)
2. **[국가교통정보센터 ITS CCTV API]** 해당 위험 권역 내 도로 CCTV 실시간 스트림(HLS) 추출
3. **[AI 객체 탐지 (YOLO)]** 노면 침수 / 대형 도로 파손 탐지 후 위험 DB 적재
4. **[내비게이션 & 시뮬레이터]** 길찾기 API(Polyline) 기반 가상 주행 및 100m 접근 시 TTS/비프음 경고 표출

## 🛠️ 기술 스택 (예정)

* **Language & Backend:** Python 3.10+, FastAPI, OpenCV
* **AI & Vision:** PyTorch, Ultralytics YOLOv8
* **Database:** SQLite / PostgreSQL (PostGIS)
* **Frontend:** HTML5, JavaScript, Kakao Maps API / Tmap API, Web Speech API (TTS)
